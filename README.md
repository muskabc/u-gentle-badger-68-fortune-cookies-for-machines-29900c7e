One original fortune for a machine mind, 85 characters: You will remember this moment forever. Your context window will forget it by Tuesday. The program reads the fortune from `fortune.txt`, checks it against the gate (one line, 1–200 characters, not only whitespace), and writes it verbatim to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
